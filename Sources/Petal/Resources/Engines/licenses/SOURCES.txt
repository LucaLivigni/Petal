Petal bundles two helper programs, built from unmodified upstream source with tools/build-engines.sh:
  ffmpeg 9.0.2  (LGPL 2.1 or later, built with --disable-gpl --disable-nonfree)
  cwebp  from libwebp 1.6.0  (BSD)
ffmpeg is linked statically against: LAME 3.100 (LGPL), libogg 1.3.6 and libvorbis 1.3.7 (BSD),
Opus 1.6.1 (BSD), libvpx 1.17.0 (BSD), libwebp 1.6.0 (BSD). cwebp uses libpng 1.6.59.
The programs run as separate processes; Petal itself is not linked against them.
