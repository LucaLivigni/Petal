Open-source licenses

Petal is built on some excellent open-source software. Here is what is inside, and under which terms.

FFmpeg, and how it is bundled

Petal includes FFmpeg to read and write formats the Mac does not handle on its own: MP3, WebM, MKV, AVI, WMV, OGG, Opus, WMA and WebP, among others. FFmpeg is a separate program inside the app, not part of Petal’s own code. Petal starts it as its own process and is not linked against it.

The FFmpeg in Petal is built without any GPL parts (--disable-gpl --disable-nonfree), so it is licensed under the GNU Lesser General Public License, version 2.1 or later. H.264 and HEVC use Apple’s VideoToolbox rather than x264 or x265.

Components

FFmpeg

LGPL 2.1 or later. A complete, cross-platform solution to record, convert and stream audio and video. ffmpeg.org

LAME

LGPL. MP3 encoder, linked into FFmpeg.

libvorbis and libogg

BSD-style license. Ogg Vorbis audio, from Xiph.Org, linked into FFmpeg.

Opus

BSD-style license. The Opus audio codec, from Xiph.Org, linked into FFmpeg.

libvpx

BSD-style license. VP8 and VP9 video, from the WebM Project, linked into FFmpeg.

libwebp

BSD-style license. WebP images, from the WebM Project. Also provides the separate cwebp program that Petal includes.

libpng

libpng license. PNG reference library, linked into FFmpeg.

Source code and license texts

The full license texts and a list of the exact source archives used for each component are included in every copy of the app, inside Petal.app/Contents/Resources/Engines/licenses. That folder is also your offer of the corresponding source for the LGPL components. If you want to build your own versions, those archives are the official releases from each project, and the script that builds them, tools/build-engines.sh, is in Petal's source repository.

Petal's own source code is licensed under the Apache License 2.0. The name Petal and the app icon are not covered by that license.

macOS frameworks

Much of what Petal does uses the frameworks that come with macOS, such as Core Image, PDFKit, AVFoundation and VideoToolbox. Those are part of your Mac and are not redistributed with Petal.

Applies to Petal 0.1.0.
